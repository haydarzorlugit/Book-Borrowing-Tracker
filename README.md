A minimal backend application (MVP) for tracking borrowed books.  
Developed using Node.js and Express, this project allows users to manage books and borrowers without authentication.

## Features

- Manage books (Create, Read, Update, Delete)
- Manage borrowers (Create, Read, Update, Delete)
- Relationship between books and borrowers
- RESTful API design
- Simple in-memory data storage

## Technologies

- Node.js
- Express.js
